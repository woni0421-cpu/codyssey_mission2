# 🏢 프로젝트 기획서: 우리 건물 입주민 전용 커뮤니티 웹앱

## 1. 프로젝트 개요
- **프로젝트명:** 우리 건물 커뮤니티 (가칭)
- **플랫폼:** 반응형 웹 애플리케이션 (Mobile First, PC Full-width 지원)
- **개발 형태:** 프론트엔드 단일 HTML 파일 (HTML, CSS, Vanilla JS) 기반의 SPA(Single Page Application) 프로토타입.

## 2. 핵심 타겟 및 목적
- **핵심 타겟:** 동일한 건물(아파트, 오피스텔 등)에 거주하는 실제 입주민
- **서비스 목적:** 신뢰할 수 있는 중고 거래, 배달비 쉐어, 분실물 찾기, 층간소음 등 건물 내 이슈의 원만한 해결 및 소통.

---

## 3. 주요 기능 명세
1. **안전한 인증 시스템 (2-Track)**
   - 세대 최초 가입자: 임대차 계약서/관리비 고지서로 관리자 승인.
   - 가족/동거인: 최초 가입자가 발급한 '24시간 유효 초대 코드'로 가입 (최대 3회).
   - **연대 책임제:** 초대받은 자가 규칙 위반 시 초대한 사람도 함께 제재.
2. **게시판 및 글쓰기**
   - 8개 카테고리 제공 (자유, 분실물, 장터/나눔, 빌려주세요, 공동구매, 배달 같이, 층간소음, 전체).
   - **장터/나눔 익명 불가:** 신뢰를 위해 해당 카테고리는 익명 작성 시스템적 차단.
   - **공백 입력 방지:** 제목/내용에 띄어쓰기만 입력 시 등록 차단 (`trim()` 적용).
3. **댓글 익명 작성 기능**
   - 댓글 작성 시 '익명으로 달기' 체크박스 제공.
   - 체크 시 회색의 '익명', 해제 시 파란색의 '본인 닉네임'으로 표시.
4. **게시글 신고 기능**
   - 게시글 상세 화면 우측 상단에 `🚨 신고` 버튼 제공.
5. **1:1 채팅 기능**
   - 게시글 작성자에게 직접 1:1 채팅 요청 및 실시간 대화 UI 제공.

---

## 4. 화면 구성
1. **인증 화면:** 서류 첨부 영역 / 초대 코드 입력 영역 (2분할 카드 UI)
2. **홈 화면:** 
   - 상단 헤더 (타이틀, 🔔 알림 아이콘 및 드롭다운 패널)
   - 카테고리 2x4 그리드 (이모티콘 포함)
   - 최신 게시글 목록 (반응형 그리드)
   - 우측 하단 글쓰기 플로팅 버튼 (FAB)
3. **글쓰기 화면:** 카테고리 선택(Select), 제목, 내용, 익명 체크박스, 등록 버튼
4. **게시글 상세 화면:** 카테고리 뱃지, 신고 버튼, 제목, 작성자, 본문, 1:1 채팅 버튼, 댓글 목록, 익명 체크박스가 포함된 댓글 입력창
5. **채팅 목록 화면:** 진행 중인 채팅방 리스트 (상대방 이름, 관련 게시글, 마지막 메시지)
6. **채팅방 화면:** 좌우 정렬된 말풍선 형태의 대화창, 하단 메시지 입력창
7. **마이페이지:** 내 프로필, 초대 코드 발급 버튼(잔여 횟수 표시), 활동 내역(내가 쓴 글/댓글, 신고 내역 등) 메뉴
8. **공통 하단 네비게이션:** 홈 / 채팅 / 마이페이지 탭

---

## 5. 동작 (Interaction & Routing)
- **SPA 라우팅:** 페이지 새로고침 없이 `display: none / flex`를 활용하여 View를 전환.
- **반응형 동작 (Responsive):** 
  - 모바일에서는 1단 세로 스크롤 위주로 동작.
  - PC(768px 이상) 확장 시 `max-width` 제한 없이 화면을 100% 꽉 채움.
  - 홈 화면 게시글 목록은 화면 너비에 따라 자동으로 2단~4단으로 확장(`auto-fill`).
  - 채팅 목록은 시선 분산을 막기 위해 화면이 커져도 1단 가로 리스트 유지.
- **유효성 검사 분기:** 글쓰기 화면에서 '장터/나눔' 선택 시 익명 체크박스 자동 해제 및 비활성화(Disabled) 처리.

## 7. 추가 기능
- **실시간 알림 패널:** 헤더의 종 모양(🔔) 아이콘에 Red Dot 배지가 표시되며, 클릭 시 내 글에 달린 댓글이나 인증 완료 알림 내역을 드롭다운으로 확인 가능.

---

## 8. 비목표 (Non-Goals) - *본 프로토타입에서 제외하는 범위*
1. **백엔드 서버 및 DB 연동:** 현재는 프론트엔드 UI/UX 검증을 위한 프로토타입이므로, 데이터는 JavaScript 배열(Memory)로 임시 관리함.
2. **실제 이미지/파일 업로드 처리:** 서류 인증 시 파일 선택 창은 열리지만, 실제 서버로 전송되거나 저장되지 않음.
3. **결제 및 송금 기능:** 중고 거래나 배달비 쉐어 시 앱 내 결제 기능은 지원하지 않으며, 대면 거래나 외부 송금 앱을 이용하도록 유도함.

---

## 9. 검증 방법 (Validation)
1. **사용성 테스트 (Usability Test):** 
   - 실제 입주민(또는 지인) 5명 이상에게 프로토타입 링크를 공유하여, 모바일 및 PC 환경에서 직접 글과 댓글을 작성해 보도록 요청.
   - 초대 코드 발급, 익명 댓글 작성, 채팅 요청 등의 핵심 플로우를 수행하는 과정에서 UI의 어색함이나 기능적 버그가 없는지 피드백을 수집하여 개선.
